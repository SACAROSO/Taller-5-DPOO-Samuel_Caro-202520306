# Taller-5-DPOO-Samuel_Caro-202520306

# Descripción
En este taller se implementaron pruebas unitarias y de integración con JUnit 5 para una aplicación de pedidos de un restaurante de hamburguesas. 
Las pruebas verifican los precios, los descuentos de los combos, el IVA, la generación de facturas y la carga de datos desde archivos de texto.

# Cambios realizados
- Se corrigió el precio de los productos ajustados para sumar el costo de los ingredientes agregados y conservar el precio al quitar ingredientes.
- Se corrigió el texto de la factura de los productos ajustados para mostrar el producto base, los ingredientes agregados y eliminados, y el precio final.
- Se corrigió el precio de los combos para aplicar el descuento sobre la suma de sus productos.
- Se corrigió el cierre de pedidos para agregar cada pedido al historial después de guardar su factura.
